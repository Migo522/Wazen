# Wazen

> **Wazen** is a smart financial management platform that helps users control spending, build savings, and achieve financial goals through a simple banking experience.

It combines **smart budgeting, automatic savings, secure digital money circles, spending insights, and personalized offers** in one platform.

Wazen is designed mainly for **Gen Z, students, and young professionals**, making financial management easier, smarter, and more engaging.

## 🎯 Project Objectives

- Make financial management simpler and more accessible.
- Help users control spending and develop saving habits.
- Provide real-time financial awareness and proactive guidance.
- Reduce the risks and effort associated with traditional money circles.
- Encourage digital banking and card usage.
- Create a unified and engaging financial experience for young users.

---

## 📌 Project Scope

### Smart Budgeting
Track and manage spending in real time.

### Goal-Based Savings
Help users save automatically toward specific financial goals.

### Digital Money Circles
Provide a safer and automated alternative to traditional money circles.

### Smart Financial Insights
Give users personalized spending alerts and recommendations.

### Offers Marketplace
Connect users with relevant offers that support their financial goals.

### Engaging Experience
Encourage better financial habits through challenges and rewards.

## 📅 Project Plan — 5 Weeks

### Week 1 — Research & Discovery
- Define the problem and project scope.
- Identify target users and their needs.
- Analyze competitors and existing solutions.
- Define user personas and key pain points.

### Week 2 — UX & User Flow
- Define the main features and requirements.
- Create Information Architecture.
- Design User Flows for the main scenarios.
- Create the initial wireframes.

### Week 3 — UI Design
- Create the Visual Identity and Design System.
- Define colors, typography, components, and UI patterns.
- Design the main application screens.
- Apply the design system across the interface.

### Week 4 — Prototype & Testing
- Build the interactive Figma prototype.
- Connect screens and user interactions.
- Conduct usability testing.
- Identify issues and improve the user experience.

### Week 5 — Finalization & Presentation
- Refine and finalize all screens.
- Complete the interactive prototype.
- Prepare the final case study and presentation.
- Present the project and collect feedback.
